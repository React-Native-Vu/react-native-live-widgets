Cài đặt & Thiết lập Tự động

Thư viện tích hợp sẵn bộ All-in-One CLI Scaffolder giúp cấu hình Xcode Widget Extension, App Groups và Android permissions chỉ với 1 câu lệnh duy nhất.

1. Quy trình dành cho Expo (SDK 50, 51, 52, 58+ CNG) Config Plugin

Thư viện tương thích 100% với Continuous Native Generation (CNG) và EAS Build: 

# Bước 1: Cài đặt thư viện
npx expo install react-native-live-widgets

# Bước 2: Thêm plugin vào app.json (xem mẫu cấu hình bên dưới)

# Bước 3: Sinh thư mục native
npx expo prebuild

# Bước 4: Tự động khởi tạo Widget Extension target & App Groups
npx react-native-live-widgets init --group group.com.yourcompany.app

# Bước 5: Chạy ứng dụng trên máy ảo
npx expo run:ios
npx expo run:android

Cấu hình Config Plugin trong tập tin app.json:

{
  "expo": {
    "name": "MyAwesomeApp",
    "slug": "my-awesome-app",
    "plugins": [
      [
        "react-native-live-widgets",
        {
          "appGroup": "group.com.yourcompany.app",
          "enableLiveActivities": true,
          "frequentUpdates": true
        }
      ]
    ]
  }
}
2. Quy trình dành cho Bare React Native CLI CLI Auto-Link 
# Cài đặt package
npm install react-native-live-widgets

# Tự động inject Xcode Widget Extension, Entitlements, Podfile và Android Manifest

JSX / TSX

Cú pháp JSX / TSX & UI.StyleSheet

Bạn có thể viết giao diện Widget theo 2 phong cách tương đương 100%: thẻ JSX tự nhiên (<VStack>, <HStack>, <Text>...) với style / mảng conditional style, hoặc bộ hàm UI.* kết hợp UI.StyleSheet.create(...). Cả Widget.setLayout() và LiveActivity.start() tự động biên dịch JSX sang JSON AST gốc.

Phong cách 1: JSX Components & StyleSheet

Hỗ trợ <VStack>, <HStack>, <ZStack>, <Grid>, <Text>, <Button>, <Toggle>, <Switch>, <Checkbox>, <Badge>, <Progress>, <Timer>, <Equalizer>, <Image>, <Gauge>, <Chart>, <Link>, <Spacer>, <Divider>. 

import {
  Widget, VStack, HStack, Text, Badge, Button, Spacer, UI
} from 'react-native-live-widgets';

const styles = UI.StyleSheet.create({
  card: { padding: 16, backgroundColor: '#0F172A', borderRadius: 18 },
  title: { fontSize: 15, fontWeight: 'bold', color: '#FFFFFF' },
});

await Widget.setLayout('main', {
  medium: (
    <VStack style={styles.card} spacing={8}>
      <HStack alignment="center">
        <Text style={styles.title}>Ca Làm Việc Hôm Nay</Text>
        <Spacer />
        <Badge text="08:00 - 17:30" backgroundColor="#064E3B" textColor="#6EE7B7" />
      </HStack>
      <Text fontSize={13} color="#94A3B8">Văn phòng Fastdo Đà Nẵng</Text>
      <Button
        title="⚡ Check-in Ngay"
        actionId="FASTDO_CHECKIN"
        backgroundColor="#0284C7"
        textColor="#FFFFFF"
        fullWidth
      />
    </VStack>
  ),
});

Phong cách 2: Functional DSL & Conditional Styles

Viết thuần TypeScript với UI.* và truyền mảng style có điều kiện tương tự React Native StyleSheet ([styles.base, isAlert && styles.alert]). Tương thích mọi bundler không dùng JSX transform. 

import { UI, Widget } from 'react-native-live-widgets';

const styles = UI.StyleSheet.create({
  card: { padding: 14, backgroundColor: '#111827', borderRadius: 16, spacing: 6 },
  label: { fontSize: 13, fontWeight: 'medium', color: '#E2E8F0' },
  errorText: { color: '#F87171', fontWeight: 'bold' },
});

const isLate = true;

await Widget.setLayout('shift', {
  medium: UI.VStack(
    styles.card,
    UI.Text('TIÊU ĐỀ BÁO CÁO', { typography: 'caption1', color: '#94A3B8' }),
    UI.Text('Trạng thái ca làm', [styles.label, isLate && styles.errorText])
  ),

Prop Kiểu Mô tả
size 'small' | 'medium' | 'large' | 'lockScreen' | 'dynamicIsland' Kích thước khung xem trước (mặc định 'medium' 338×158dp).

v1.2.1 Mới

Vùng Bấm Động Từng Pixel, Chronometer & Swift 6 Ready

Bản phát hành v1.2.1 tái cấu trúc toàn diện hệ thống tương tác cảm ứng trên Android Home Screen Widgets, tích hợp đồng hồ đếm ngược phần cứng native và tương thích hoàn toàn Swift 6 Language Mode trên Xcode mới.

1. Exact Dynamic Hit Layer (rn_hit_layer)

Thay thế hoàn toàn lưới cố định cũ bằng FrameLayout động (rn_live_widget_hit_zone.xml). Giải thuật computeCanvasMapping ánh xạ chính xác toạ độ từ Bitmap Canvas sang khung Launcher thật (xử lý bù viền fitCenter letterboxing). Bấm vào nút/checkbox nào ăn đúng 100% nút đó, vùng trống hoàn toàn không kích hoạt nhầm.

2. Native Chronometer Countdown (Android)

Tích hợp trực tiếp android.widget.Chronometer với setChronometerCountDown(true) và baseMillis = SystemClock.elapsedRealtime() + remainingMillis. Khi có timer đếm ngược, hệ thống ẩn text tĩnh trên Bitmap để đồng hồ native tự chạy giật lùi 1s/lần mà không phải vẽ lại ảnh Canvas.

3. Nội suy Biến động & defaultChecked Store

DynamicWidgetStateStore hỗ trợ nội suy chuỗi mẫu {{id}}, {{title}}, giá trị bộ đếm phẳng và tự động lưu trạng thái khởi tạo defaultChecked của công tắc checked: true ngay lần render đầu, giúp tắt công tắc mượt mà ngay lần chạm đầu tiên.

4. Tương thích Swift 6 Language Mode (iOS)

Khắc phục lỗi biên dịch type '()' cannot conform to 'View' trên Xcode mới bằng cách đóng gói closure cho Font trong renderText(), tách logic accessibility sang hàm thuần buildAccessibilityView(content:) -> AnyView, và bổ sung EmptyView() cho các nhánh ContainerStyleModifier.

Hình ảnh & Biểu tượng: UI.Image (5 nguồn ảnh)

Auto-Cache 360px

Hỗ trợ 5 nguồn ảnh: url (tự tải ngầm, nén tối đa 360px tránh vượt ngưỡng 30MB WidgetKit và lưu vào App Group cache), base64 (QR/Barcode), systemName (SF Symbols iOS / Vector icon Android), assetName, và filePath. Hỗ trợ fallbackSystemName, contentMode ('fill' | 'fit'), symbolEffect (iOS 17+: bounce, pulse, variableColor), và widgetAccentable.

// 2. Icon hệ thống với hiệu ứng iOS 17+
UI.Image({

Mở rộng Component Native: UI.Custom & DynamicNodeRegistry

SwiftUI & Kotlin Canvas

Khi cần nhúng đồ họa hoặc View Native đặc thù mà DSL chưa có sẵn, bạn đăng ký custom renderer trong LiveWidgetsBundle.swift (iOS) và MainApplication.kt (Android), rồi gọi qua UI.Custom('WeatherCard', { ... }).

3. React Hooks (Fast Refresh Resilient) & SharedStorage

Hooks & App Group

Các Hook tự động dọn dẹp listener khi unmount và đồng bộ 2 chiều qua App Group (iOS) / SharedPreferences (Android). Với các nghiệp vụ quan trọng (như Chấm công) khi App bị người dùng Force-Kill, hãy dùng mô hình Offline-First State Queue qua SharedStorage. 

import {
  useWidgetAction, useLiveActivity, useWidgetState, SharedStorage
} from 'react-native-live-widgets';

// 1. Lắng nghe bấm nút từ Widget / Dynamic Island (an toàn với Fast Refresh)
useWidgetAction('INCREMENT', (actionId, payload) => {
  console.log('Clicked:', actionId, payload);
});

// 2. Quản lý vòng đời Live Activity bằng Hook
const { activityId, isActive, start, update, end } = useLiveActivity();

// 3. State đồng bộ 2 chiều với Native Store
const [counter, setCounter, resetCounter] = useWidgetState('widget_counter', 0);

// 4. Đọc / ghi trực tiếp vào App Group / SharedPreferences
await SharedStorage.set('pending_checkin', { timestamp: Date.now() }, 'group.com.yourapp');
const saved = await SharedStorage.get('pending_checkin', 'group.com.yourapp');

4. Đồng bộ API Ngầm kể cả khi Kill App (Widget.setRemoteConfig)

URLSession & AlarmManager

Khi App bị vuốt tắt hoàn toàn, Native Extension sẽ tự gọi API định kỳ theo refreshIntervalMinutes (alias intervalMinutes) hoặc ngay khi người dùng bấm nút actionId: 'refresh', điền JSON trả về vào các biến {{ten_bien}} và tự động cập nhật biến hệ thống {{_lastSyncTime}} (HH:mm:ss). Lưu ý: iOS cấp hạn mức ~40–70 lần reload/ngày (WidgetKit Budget) và Android Doze Mode gom tác vụ nền; nếu cần cập nhật từng giây, hãy kết hợp Server Push APNs/FCM. 

await Widget.setRemoteConfig('main', {
  url: 'https://api.yourcompany.com/v1/widget-summary',
  method: 'GET',
  headers: { Authorization: `Bearer ${accessToken}` },
  refreshIntervalMinutes: 15, // Chu kỳ gợi ý cho OS
}, 'group.com.yourcompany.app');

3 Trụ Cột Kiến Trúc & UI Intermediate Representation (IR)

Thay vì đi thẳng từ DSL → Bitmap thiếu ngữ nghĩa, thư viện áp dụng kiến trúc chuẩn công nghiệp với Semantic Tree độc lập khỏi Visual Renderer:

✅ Điểm 1: Native Semantic Coverage

Phù hợp giới hạn whitelist của Android RemoteViews: mọi Text/Button/Toggle quan trọng đều có Semantics; thành phần đồ họa Canvas (Gauge, Chart, Equalizer) sinh kèm Accessibility Description thay thế.

✅ Điểm 2: Native-first, Canvas-when-needed

Chronometer và FrameLayout Hit Layer chạy hoàn toàn bằng Native RemoteViews; Canvas 2D chỉ vẽ các phần thực sự cần vẽ (đồ họa phức tạp, Gauge, Sparkline), giảm RAM và pin.

✅ Điểm 3: Semantic Tree độc lập Renderer (UI IR)

Cây UI IR tách làm 3 phần: Visual Tree, Semantic Tree và State Bindings — dùng API Widget.inspectIR() và Widget.compileIR() để kiểm toán trực tiếp kế hoạch render. 

import { Widget, UI } from 'react-native-live-widgets';

const layout = UI.VStack(
  { padding: 16, backgroundColor: '#0F172A' },
  UI.Text('BẢNG ĐIỀU KHIỂN CHẤM CÔNG', { typography: 'title2' }),
  UI.Progress({ value: 0.86, accessibilityLabel: 'Tiến độ hoàn thành ca' }),
  UI.Button({ title: 'Check In', actionId: 'toggle:attendance' }),
  UI.Gauge(0.92, { label: 'Hiệu suất' })
);

// Phân tích chiến lược Native vs Canvas & tóm tắt Trợ năng TalkBack/VoiceOver
console.log(Widget.inspectIR(layout));
const ir = Widget.compileIR(layout);
console.log(ir.renderStrategy, ir.semanticSummary);

Lớp Trợ năng Chuẩn hóa (VoiceOver iOS & TalkBack Android)

Mọi node hỗ trợ đầy đủ AccessibilityProps: accessible, accessibilityRole ('header' | 'button' | 'progressbar' | 'checkbox' | 'switch' | 'image' | 'summary'), accessibilityLabel, accessibilityHint, và accessibilityValue. Trên Android, engine tự động duyệt đệ quy để gán tóm tắt vào contentDescription của Canvas và từng Hit Zone.

Xử lý Sự cố Thường gặp (Troubleshooting)

  • Widget hiện "Chọn 1 mẫu UI trong app để hiển thị": Kiểm tra App Group ID giữa Main App và Widget Extension đã trùng khớp chưa (vd group.<bundle_id>) và đảm bảo đã gọi await Widget.setLayout('main', ...).
  • Dynamic Island Compact bị tràn chiều ngang khi dùng UI.Timer: Đảm bảo đặt fontSize gọn (11–13) cho compactTrailing; thư viện đã tự tính độ rộng compactWidth tối ưu theo thời lượng còn lại.
  • Ảnh từ URL mạng (https://...) không hiện trên Widget: Đảm bảo URL là HTTPS hợp lệ; thư viện tự tải ngầm, nén xuống 360px để không vượt giới hạn 30MB của WidgetKit và reload lại Widget khi tải xong.
  • Lỗi build Swift 6 type '()' cannot conform to 'View' trên Xcode mới: Cập nhật lên phiên bản 1.2.1 trở lên (npm install react-native-live-widgets@latest).
