Cài đặt & Thiết lập Tự động

Thư viện tích hợp sẵn bộ All-in-One CLI Scaffolder giúp cấu hình Xcode Widget Extension, App Groups và Android permissions chỉ với 1 câu lệnh duy nhất.

1. Quy trình dành cho Expo (SDK 50, 51, 52, 58+ CNG) Config Plugin

Thư viện tương thích 100% với Continuous Native Generation (CNG) và EAS Build: 

# Bước 1: Cài đặt thư viện
npx expo install react-native-live-widgets

# Bước 2: Thêm plugin vào app.json (xem mẫu cấu hình bên dưới)

# Bước 3: Sinh thư mục native
npx expo prebuild

# Bước 4: Tự động khởi tạo Widget Extension target & App Groups
npx react-native-live-widgets init --group group.com.yourcompany.app

# Bước 5: Chạy ứng dụng trên máy ảo
npx expo run:ios
npx expo run:android

Cấu hình Config Plugin trong tập tin app.json:

{
  "expo": {
    "name": "MyAwesomeApp",
    "slug": "my-awesome-app",
    "plugins": [
      [
        "react-native-live-widgets",
        {
          "appGroup": "group.com.yourcompany.app",
          "enableLiveActivities": true,
          "frequentUpdates": true
        }
      ]
    ]
  }
}
2. Quy trình dành cho Bare React Native CLI CLI Auto-Link 
# Cài đặt package
npm install react-native-live-widgets

# Tự động inject Xcode Widget Extension, Entitlements, Podfile và Android Manifest
npx react-native-live-widgets init --group group.com.yourcompany.app

# Khởi chạy dự án
npx react-native run-ios
npx react-native run-android

Cú pháp JSX / TSX & Khung Xem Trước <WidgetPreview>

Viết code widget tự nhiên như đang viết React Component thông thường với thẻ JSX và nhúng ngay vào ứng dụng để test giao diện mà không cần ra màn hình chính.

Nhúng <WidgetPreview> vào App để xem trước kích thước Small, Medium, Large 

import React from 'react';
import { View } from 'react-native';
import { 
  WidgetPreview, 
  VStack, 
  HStack, 
  Text, 
  Badge, 
  Button, 
  Widget 
} from 'react-native-live-widgets';

export default function HomeScreen() {
  return (
    <View style={{ flex: 1, padding: 16 }}>
      {/* 1. Component Xem trước trực tiếp trong ứng dụng */}
      <WidgetPreview 
        size="medium" 
        showBadge 
        interactiveSizeSwitch 
        onAction={(actionId) => console.log('User click button:', actionId)}
      >
        <VStack padding={16} backgroundColor="#0F172A" borderRadius={18}>
          <HStack justifyContent="spaceBetween" alignItems="center">
            <Text fontSize={15} fontWeight="bold" color="#FFFFFF">Ca Làm Việc Hôm Nay</Text>
            <Badge text="08:00 - 17:30" backgroundColor="#064E3B" textColor="#6EE7B7" />
          </HStack>
          
          <Text fontSize={13} color="#94A3B8" margin={{ top: 8 }}>
            Vị trí: Văn phòng Fastdo Đà Nẵng
          </Text>
          
          <Button 
            title="⚡ Check-in Ngay" 
            actionId="FASTDO_CHECKIN" 
            backgroundColor="#0284C7" 
            color="#FFFFFF"
            margin={{ top: 12 }} 
          />
        </VStack>
      </WidgetPreview>
    </View>
  );
}
v1.2.1 Mới

Vùng Bấm Động Từng Pixel & Đồng Hồ Native Android

Tối ưu độ chính xác cảm ứng 100% không lệch toạ độ, tích hợp Chronometer đếm ngược thời gian thực và tương thích hoàn toàn Swift 6.

Exact Dynamic Hit Layer & Canvas Mapping

Thay thế hoàn toàn lưới chia ô cố định cũ bằng FrameLayout động (rn_hit_layer). Giải thuật computeCanvasMapping bù trừ viền co giãn fitCenter, giúp bấm trúng 100% nút, triệt tiêu mọi cú chạm ảo vào khoảng trống.

Native Chronometer Countdown (Android)

Tích hợp trực tiếp android.widget.Chronometer với setChronometerCountDown(true). Đếm ngược giật lùi 1 giây/lần mượt mà ngay trên Home Screen mà không cần vẽ lại Canvas Bitmap, tiết kiệm tối đa pin.

Declarative UI Engine Catalog (`UI.*`)

Nếu không dùng JSX, bạn có thể sử dụng bộ Builder API UI.* với đầy đủ TypeScript autocompletion:

UI.Timer — Đếm giờ Phần cứng 0% CPU

Tự động đếm lùi hoặc tiến theo thời gian thực:

UI.Timer({
  // Đếm lùi từ 25 phút
  targetTimestamp: Date.now() + 25 * 60 * 1000,
  isCountDown: true,
  color: '#38BDF8',
  fontSize: 28,
  fontWeight: 'heavy'
})
UI.Equalizer — Sóng nhạc liên tục Realtime

Hiển thị sóng âm chuyển động cho audio/podcast:

UI.Equalizer({
  barCount: 5,
  color: '#A855F7',
  height: 20,
  animated: true
})
UI.Progress — Bar, Segmented & Circle ProgressStyle

Thanh tiến trình đơn, chia chặng hoặc vòng tròn:

// Thanh chia chặng (Segmented)
UI.Progress({
  style: 'segmented',
  currentSegment: 2,
  totalSegments: 4,
  tintColor: '#10B981',
  height: 6
})
UI.Button & useWidgetAction AppIntents

Nút bấm tương tác 2 chiều với React Native:

// 1. Đặt nút trong Widget
UI.Button({
  title: 'Check-in',
  actionId: 'ACTION_CHECKIN',
  backgroundColor: '#0284C7'
});

// 2. Lắng nghe trong App bằng Hook
useWidgetAction('ACTION_CHECKIN', () => {
  doCheckin();
});

Core API Reference

Tài liệu chi tiết các phương thức cốt lõi của thư viện:

LiveActivity API (iOS 16.1+ & Android 16 Live Updates)

Core
Hàm Tham số Mô tả
LiveActivity.start(config) LiveActivityStartConfig Bắt đầu một Live Activity và kích hoạt Dynamic Island. Trả về activityId.
LiveActivity.update(id, data) id: string, data: object Cập nhật nội dung, tiến trình hoặc trạng thái Live Activity đang chạy.
LiveActivity.end(id, finalState) id: string, dismissalPolicy? Kết thúc Live Activity (chính sách đóng: default hoặc immediate).
LiveActivity.list() none Liệt kê tất cả các Live Activities hiện đang hoạt động.
LiveActivity.getPushToken(id) id: string Lấy Activity Push Token để server có thể push cập nhật trực tiếp qua APNs/FCM.

Widget API (Home Screen Widgets & App Groups)

WidgetKit
Hàm Tham số Mô tả
Widget.reload(kind, data) kind: string, data: WidgetData Cập nhật dữ liệu và yêu cầu hệ điều hành reload lại giao diện widget.
Widget.setLayout(kind, sizes) small?, medium?, large? Thiết lập bố cục riêng biệt cho từng kích cỡ widget (hỗ trợ cả JSX).
Widget.setRemoteConfig(config) RemoteFetchConfig Đăng ký URL API ngầm để hệ điều hành tự động kéo dữ liệu kể cả khi ứng dụng bị tắt.
Widget.pinWidget(kind) kind: string Hiển thị hộp thoại hệ thống ghim tiện ích ra Home Screen ngay trong App (Android).
