Cài đặt & Thiết lập tự động

Thư viện cung cấp bộ công cụ All-in-One CLI Scaffolder giúp tự động tạo Xcode Extension target, cấu hình App Groups và Android permissions chỉ với 1 câu lệnh duy nhất.

1. Quy trình dành cho Expo (SDK 50, 51, 52, 58+) Config Plugin 
# Bước 1: Cài đặt package
npx expo install react-native-live-widgets

# Bước 2: Thêm plugin vào app.json
# (xem mẫu cấu hình bên dưới)

# Bước 3: Sinh thư mục native
npx expo prebuild

# Bước 4: Tự động cấu hình Widget Extension target & App Groups
npx react-native-live-widgets init --group group.com.yourcompany.app

# Bước 5: Chạy ứng dụng trên Simulator
npx expo run:ios

Cấu hình plugin trong app.json:

{
  "expo": {
    "plugins": [
      [
        "react-native-live-widgets",
        {
          "appGroup": "group.com.yourcompany.app",
          "enableLiveActivities": true,
          "frequentUpdates": true
        }
      ]
    ]
  }
}
2. Quy trình dành cho Bare React Native CLI 
npm install react-native-live-widgets
# Tự động inject Xcode target, entitlements, podfile và android permissions
npx react-native-live-widgets init --group group.com.yourcompany.app
npx react-native run-ios

Declarative UI Engine (`UI.*`)

Không cần viết SwiftUI hay Kotlin RemoteViews! Khai báo cây giao diện trực tiếp trong TypeScript và hệ thống sẽ tự động ánh xạ sang Native:

🚀 Live Activity & Dynamic Island iOS 16.1+ 
await LiveActivity.start({
  activityName: 'Delivery',
  appGroup: 'group.com.myapp',
  layout: UI.VStack({
    padding: 16,
    backgroundColor: '#0F172A',
    children: [
      UI.Text('Tài xế đang giao đơn', { 
        color: '#FFFFFF', 
        fontSize: 15, 
        fontWeight: 'bold' 
      }),
      UI.Progress({ 
        style: 'bar', 
        value: 0.7, 
        tintColor: '#38BDF8', 
        height: 6 
      })
    ]
  }),
  dynamicIsland: {
    compactLeading: UI.Text('☕', { fontSize: 13 }),
    compactTrailing: UI.Text('12m', { color: '#38BDF8', fontWeight: 'bold' }),
    expanded: {
      leading: UI.Text('COFFEE EXPRESS', { fontSize: 11 }),
      trailing: UI.Text('12 mins', { fontSize: 16, fontWeight: 'bold' })
    }
  }
});
⚡ Home Screen Widget Tương Tác 2 Chiều AppIntents 
// Cập nhật Home Screen Widget với nút bấm tương tác
Widget.reload('main', {
  layout: UI.VStack({
    padding: 14,
    backgroundColor: '#0F172A',
    alignment: 'center',
    children: [
      UI.Text('BỘ ĐẾM TIỆN ÍCH', { color: '#94A3B8', fontSize: 11 }),
      UI.Text(`${counter}`, { color: '#38BDF8', fontSize: 32, fontWeight: 'heavy' }),
      UI.Button({
        title: '+1 TĂNG SỐ',
        actionId: 'INCREMENT',
        backgroundColor: '#0284C7',
        color: '#FFFFFF'
      })
    ]
  })
});

// Lắng nghe khi người dùng bấm nút trên mặt Widget
LiveActivity.registerActionHandler((actionId) => {
  if (actionId === 'INCREMENT') {
    setCounter(c => c + 1);
  }
});
